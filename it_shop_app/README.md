IT-SHOP Финалочка

Практическая работа по автоматизированному тестированию с Pytest

---

1. О проекте

IT-SHOP — учебное консольное приложение, имитирующее работу интернет-магазина.

В приложении реализованы основные возможности интернет-магазина:

- Просмотр каталога товаров.
- Добавление и удаление товаров из корзины.
- Расчёт стоимости заказа.
- Применение промокодов.
- Расчёт стоимости доставки.
- Проверка данных покупателя.
- Оформление заказа.

Структура проекта

Файл| Назначение
"shop.py"| Бизнес-логика магазина. Основной объект тестирования
"main.py"| Консольное меню для покупателя
"test_shop.py"| Ваш файл с автоматизированными тестами

Важно: тестировать необходимо функции из "shop.py". Проверять работу консольного меню "main.py" не требуется.

---

2. Подготовка к работе

Требования:

- Python версии 3.9 или новее.
- Установленный Pytest.

Дополнительные библиотеки для запуска самого приложения не нужны.

Шаг 1. Запуск приложения

Откройте терминал в папке проекта и выполните:

python main.py

Если команда не работает, попробуйте:

python3 main.py

После запуска откроется консольное меню интернет-магазина. Попробуйте добавить товары в корзину, удалить их и оформить заказ.

Шаг 2. Установка Pytest

Выполните команду:

python -m pip install pytest

Проверить установку можно командой:

pytest --version

Шаг 3. Создание файла тестов

В папке проекта создайте новый файл:

"test_shop.py"

В нём необходимо разместить все написанные вами тесты.

---

3. Основное задание

Ваша задача — написать автоматизированные тесты для всех функций, представленных в "shop.py".

Для каждой функции необходимо проверить правильность работы и поведение при получении некорректных данных.

3.1. Поиск товара — "find_product()"

Проверьте:

- Успешный поиск существующего товара.
- Попытку найти товар с несуществующим ID.

  3.2. Создание корзины — "create_cart()"

Проверьте:

- Создание пустой корзины.
- Корректность типа возвращаемого значения.

  3.3. Добавление товара — "add_to_cart()"

Проверьте:

- Успешное добавление товара.
- Добавление нескольких единиц одного товара.
- Попытку добавить отрицательное или нулевое количество.
- Попытку добавить больше товаров, чем есть на складе.
- Попытку добавить несуществующий товар.

  3.4. Удаление товара — "remove_from_cart()"

Проверьте:

- Успешное удаление товара.
- Уменьшение количества товара в корзине.
- Полное удаление товара при удалении всего количества.
- Попытку удалить товар, которого нет в корзине.
- Попытку удалить отрицательное или нулевое количество.

  3.5. Расчёт стоимости — "calculate_subtotal()"

Проверьте:

- Расчёт стоимости одного товара.
- Расчёт стоимости нескольких разных товаров.
- Расчёт стоимости нескольких единиц одного товара.
- Расчёт стоимости пустой корзины.

  3.6. Применение промокода — "apply_coupon()"

В приложении доступны следующие промокоды:

Промокод| Размер скидки
"SALE10"| 10%
"SALE20"| 20%

Проверьте:

- Применение промокода "SALE10".
- Применение промокода "SALE20".
- Использование несуществующего промокода.
- Передачу отрицательной суммы.

  3.7. Расчёт доставки — "calculate_delivery()"

Проверьте:

- Стандартную доставку.
- Экспресс-доставку.
- Бесплатную доставку при заказе от 5000 рублей.
- Передачу неизвестного способа доставки.

  3.8. Проверка покупателя — "validate_customer()"

Проверьте:

- Корректные данные покупателя.
- Отсутствие имени.
- Некорректный email.
- Некорректный номер телефона.

  3.9. Оформление заказа — "checkout()"

Проверьте:

- Успешное оформление заказа.
- Оформление заказа с промокодом.
- Оформление заказа с экспресс-доставкой.
- Попытку оформить заказ с пустой корзиной.
- Оформление заказа с некорректными данными покупателя.

4. Обязательные требования к тестам

При выполнении работы необходимо использовать все изученные возможности Pytest.

Обычные тесты| Создание тестовых функций
"assert"| Проверка ожидаемых результатов
"@pytest.mark.parametrize"| Проверка нескольких наборов данных в одном тесте
"@pytest.fixture"| Подготовка и повторное использование тестовых данных

Обратите внимание:

- Не создавайте отдельный тест для каждого одинакового сценария, если их можно объединить с помощью параметризации.
- Используйте фикстуры для подготовки повторяющихся данных: корзин, покупателей и других объектов.
- Проверяйте как успешное выполнение функций, так и обработку некорректных данных.

---

5. Запуск и проверка тестов

Находясь в папке проекта, выполните:

pytest -v

Pytest автоматически найдёт файл "test_shop.py" и запустит содержащиеся в нём тесты.

Как понять результат?

Результат| Значение
<span>PASSED</span>| Тест успешно пройден
<span>FAILED</span>| Тест завершился с ошибкой

Если тест завершился с ошибкой, изучите сообщение Pytest и попробуйте определить причину.
